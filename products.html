ParancU for iOS

Retrieve and inspect supporting passages from your own documents, combining multilingual semantic matching with lexical signals.

Import PDFs or text, capture text with camera/image OCR, and retrieve and inspect source evidence.

Retrieval runs locally after corpus preparation. Preparation currently sends source chunks to OpenAI using a user-supplied API key.

02 / WEB
Experimental web application

ParancU Agent Lab

An experimental web application extending document retrieval with evidence-grounded answer generation, verification and limited recovery.

Imported prepared corpora support browser-local retrieval only. Separate server-assisted workflows use OpenAI for preparation, answer generation and verification.

Verification is model-based and does not guarantee correctness.
