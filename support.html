ParancU Support

ParancU is a local-first mobile application for retrieving evidence from your own documents.

Getting started

Import a PDF, paste text, scan a page or select an image, then prepare the corpus and ask questions from the Ask tab.

A valid OpenAI API key is currently required during corpus preparation to generate a short summary and one guiding question for each source chunk. After preparation, corpus persistence, multilingual E5 embedding, semantic-lexical scoring, ranking, and evidence inspection are performed locally on the device.
