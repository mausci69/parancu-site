The technical approach separates finding a relevant passage from deciding whether it supports a complete answer.

From question to source

Implemented retrieval
  1. 01 / PREPARE

    Build a corpus

    Split source text into passages and associate retrieval metadata with each passage.

  2. 02 / MATCH

    Compare meanings and anchors

    Multilingual E5 embeddings provide semantic matching; lexical anchors give exact names and distinctive terms a role in ranking.

  3. 03 / INSPECT

    Return the evidence

    Expose candidate passages, guiding questions, summaries and scores so the selected source remains visible.

Retrieval scores express ranking signals. They are not probabilities of truth or calibrated confidence.

A boundary that matters

Similarity is useful.
Sufficiency is a separate question.

A passage may discuss the right topic but omit the requested date, condition or relationship. Decision Lab studies individual and paired evidence judgments, including missing-information diagnosis.

Agent Lab adds generation and model-based verification to retrieval. A quotation can be present in a source without establishing that every claim is supported.

Processing boundaries

Local depends on the workflow.

ParancU iOS

Corpus persistence, E5 inference, scoring and evidence inspection run on-device after preparation.

Preparation sends source chunks to OpenAI for summaries and guiding questions using your API key.

Read the iOS privacy policy →

Agent Lab: imported corpus

A prepared corpus can be held in browser memory and queried using browser E5, without OpenAI.

This mode retrieves evidence; it does not generate or verify answers. Reloading clears the imported corpus.

Agent Lab: server-assisted

TXT content is sent to the server. Preparation and generated/verified answers use OpenAI and a user-provided key.

Server storage and optional operational telemetry have separate boundaries from the iOS app.

In development

Representing access
to facts.

ParancU 2.0 investigates exact source-sentence chunks, natural-language factual units and multiple generated questions linked to their source. Implemented components preserve identifiers, offsets and embedding compatibility.

These newer components are separate from Agent Lab’s overlapping three-sentence retrieval pipeline. Structural provenance does not certify semantic fidelity or complete question coverage.
