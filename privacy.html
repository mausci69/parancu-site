Privacy Policy

Last updated: August 5, 2026

ParancU is designed around a local-first architecture. The app does not require an account and does not collect personal profile information.

Documents and local data

Documents, extracted text, prepared corpora, embeddings, retrieval results and app settings are stored locally on the user's device unless the user explicitly exports or shares them.

OpenAI API use

A user-provided OpenAI API key is currently required during corpus preparation. Source text is sent to the OpenAI API only for the purpose of generating retrieval metadata such as summaries and guiding questions.

The API key is entered by the user and stored locally on the device. ParancU does not operate an intermediary server for this processing.

Local retrieval

Embedding inference, semantic and lexical scoring, ranking, corpus persistence and evidence inspection are performed locally on the device after corpus preparation.

Analytics and advertising

ParancU does not include advertising and does not use third-party analytics or tracking services.
